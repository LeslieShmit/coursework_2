# Job parser — Парсер вакансий HH.ru

## Описание проекта

Проект предназначен для поиска вакансий на сайте HH.ru через публичное API, сохранения результатов в JSON-файл и дальнейшей работы с полученными данными.

Функциональность программы:

* поиск вакансий по ключевому слову;
* сохранение вакансий в JSON-файл;
* предотвращение сохранения дубликатов;
* вывод найденных вакансий в удобочитаемом виде;
* вывод топ-N вакансий по уровню зарплаты;
* поиск вакансий по ключевому слову в требованиях и обязанностях.

## Пример работы программы

После запуска программа предложит:

1. Ввести имя файла для сохранения вакансий.
2. Ввести поисковый запрос.
3. Выбрать одно из действий:

```text
1. Вывести найденные вакансии
2. Топ самых высокооплачиваемых вакансий
3. Поиск вакансий по ключевому слову в описании
```

### Пример

```text
Введите имя файла, в который будет записан результат работы программы
python_vacancies.json

Введите ключевое слово для поиска среди вакансий на сайте hh.ru
Python

Выберете одну из предложенных опций и введите его номер без точки:
1. Вывести найденные вакансии
2. Топ самых высокооплачиваемых вакансий
3. Поиск вакансий по ключевому слову в описании
```

## Основные классы

### HH

Класс для работы с API HH.ru.

Методы:

* `_connect_to_api()` — подключение к API;
* `load_vacancies()` — получение списка вакансий.

### VacancyWorker

Класс вакансии.

Содержит:

* название вакансии;
* ссылку на вакансию;
* зарплату;
* работодателя.

Поддерживает сравнение вакансий по зарплате через перегруженные операторы:

```python
>
<
>=
<=
==
```

### JSONFileWorker

Класс для работы с JSON-файлами.

Позволяет:

* сохранять вакансии;
* получать вакансии по ключевому слову;
* очищать файл.
